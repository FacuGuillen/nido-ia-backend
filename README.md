# Nido IA - Backend

Microservicio desarrollado en Python para la integración y procesamiento de IA.

## Tecnologías utilizadas
* **Lenguaje:** Python
* **Framework / API:** Flask
* **IA:** Gemini
* **Base de datos:** PostgreSQL

## Descripción
Este repositorio contiene la lógica del servidor y los endpoints encargados de procesar consultas mediante inteligencia artificial para la aplicación.
